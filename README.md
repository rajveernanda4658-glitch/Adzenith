# AdZenith Website

A modern, responsive one-page website for **AdZenith** (media house) featuring:
- Web Development
- Performance Marketing
- Creatives

## Run locally

You can open `index.html` directly in a browser, or run a small local server.

### Option A: Python (if installed)

```bash
python -m http.server 5173
```

Then open `http://localhost:5173`.

### Option B: Node (if installed)

```bash
npx serve .
```

## Customize

- Update contact details in `index.html` (email/phone/location)
- Replace the “Selected work” and testimonials with real client examples
- Adjust colors and gradients in `styles.css` under `:root`
